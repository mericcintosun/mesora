# Security

## 1. Contract addresses and chain id

None. Mesora has no smart contract and talks to no chain. There is no `contracts/` directory.

## 2. Wallet permissions requested

None. The app never connects a wallet and never calls `eth_requestAccounts`, `eth_sign` or `personal_sign`.

## 3. Approvals

None. The app never asks for a token approval or a signature of any kind.

## 4. Source repo

https://github.com/mericcintosun/mesora

Report a problem by opening an issue there. For what data leaves the browser, see "Privacy: what leaves the browser" in README.md.
